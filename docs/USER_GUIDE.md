# Pathways User Guide

## Getting Started

### Signing Up

1. Visit the Pathways landing page
2. Click "Get Started" or "Sign Up"
3. Fill in your information:
   - Full name
   - Email address
   - Password (minimum 8 characters)
   - Role (Student, Academic Supervisor, Field Supervisor, or Admin)
4. Click "Create Account"
5. Sign in with your credentials

### Password Reset

If you forget your password:
1. Click "Forgot Password?" on the sign-in page
2. Enter your email address
3. Check your email for a reset link (valid for 1 hour)
4. Create a new password

## For Students

### Dashboard

Your dashboard shows:
- Current internship status (if active)
- Progress percentage
- Quick links to key features

### Browse Internships

1. Navigate to "Internships" from the sidebar
2. Browse available training programs
3. View program details: organization, duration, available seats
4. Check application deadlines

### Apply to a Program

1. Click on a program to view details
2. Click "Apply Now"
3. Write a cover letter (50-2000 characters)
4. Submit your application
5. Wait for field supervisor approval

### My Internship

Once your application is approved:
- View internship details
- Track progress percentage
- Access reports and evaluations

### Weekly Reports

1. Go to "My Reports" in the sidebar
2. Click "New Report"
3. Fill in:
   - Report title
   - Week number
   - Content (describe your activities)
   - Attachments (optional - upload files)
4. Submit for review

**Note**: Reports start as DRAFT. Submit them for supervisor review.

### View Evaluations

1. Go to "Evaluations" in the sidebar
2. View all evaluations from your field supervisor
3. See:
   - Overall score (with star rating)
   - Criteria breakdown
   - Feedback comments
   - Cosign status

### Messages

1. Click "Messages" in the sidebar
2. Select a conversation to view messages
3. Type a message and press Enter or click Send
4. Conversations include your academic and field supervisors

### Notifications

1. Click the bell icon in the header for unread count
2. Click "Notifications" to view all
3. Click on a notification to go to the related item
4. Notifications are marked as read automatically

## For Academic Supervisors

### Dashboard

Your dashboard shows:
- Assigned students count
- Programs you've created
- Pending items (applications, reports, evaluations)

### Create Programs

1. Go to "Programs" in the sidebar
2. Click "Create Program"
3. Fill in:
   - Program title
   - Organization name
   - Description
   - Duration (weeks)
   - Available seats
   - Application deadline (optional)
4. Click "Create"

### Manage Programs

1. Go to "Programs"
2. View your programs with:
   - Applicant count
   - Active internship count
3. Click "View" to see details
4. Click "Edit" to modify

### View Students

1. Go to "Students" in the sidebar
2. Click on a student to see:
   - Profile information
   - Current internship
   - Weekly reports
   - Evaluations (cosign pending)

### Review Reports

1. Go to "Reports" in the sidebar
2. Click on a report to review
3. Read the report content and attachments
4. Add your review:
   - Decision: Approve, Reject (Needs Revision), Keep Under Review
   - Feedback comment
5. Submit review

### Cosign Evaluations

1. Go to "Students" → Select a student
2. Scroll to "Evaluations" section
3. Review the evaluation submitted by the field supervisor
4. Click "Cosign" to approve
5. Student will be notified

### Messages

Communicate with students and field supervisors in dedicated conversations.

## For Field Supervisors

### Dashboard

Your dashboard shows:
- Assigned students
- Pending applications
- Active internships

### Review Applications

1. Go to "Applications" in the sidebar
2. View pending applications queue
3. Each application shows:
   - Student name and email
   - Program details
   - Cover letter
4. For each application:
   - Select an academic supervisor to assign
   - Click "Approve" to create internship
   - Or click "Reject" to decline

**Note**: Approval automatically creates:
- An internship record
- A group conversation
- Notifications to all parties

### Submit Evaluations

1. Go to "Evaluations" in the sidebar
2. Select an internship from the dropdown
3. Specify the evaluation period (e.g., "Week 1-4")
4. Rate criteria (0-10 scale):
   - Attendance & Punctuality
   - Technical Skills
   - Communication Skills
   - Teamwork & Collaboration
   - Problem Solving
   - Work Quality
   - Initiative & Proactivity
   - Professionalism
   - Add custom criteria as needed
5. Provide an overall comment
6. Submit for academic supervisor cosign

### View Student Profiles

1. Go to "Students" in the sidebar
2. Click on a student to view:
   - Profile and program details
   - Submitted reports
   - Evaluations

### Messages

Participate in conversations with students and academic supervisors.

## For Admins

### Users Management

1. Go to "Users" in the sidebar
2. View all registered users
3. See: name, email, role, join date

### Programs Management

1. Go to "Programs" in the sidebar
2. View all programs across the platform
3. See: creator, applicant count, active internship count

### Audit Logs

1. Go to "Audit Logs" in the sidebar
2. View all system actions
3. Filter by:
   - Action type
   - Entity type
   - User
4. See detailed action history for compliance

## Common Features

### Settings

Available to all users:
1. Go to "Settings" in the sidebar
2. **Profile Tab**: Update name and email
3. **Password Tab**: Change your password
4. **Notifications Tab**: Manage notification preferences

### Notifications

- Bell icon shows unread count
- Types of notifications:
  - New messages
  - Report submissions
  - Report reviews
  - Evaluation postings
  - Application decisions

### Messages

- Real-time messaging
- Multi-participant conversations
- Read receipts
- Support for attachments

## Tips & Best Practices

### For Students
- Submit reports weekly on time
- Be detailed in your reports
- Check evaluations regularly for feedback
- Respond to messages promptly

### For Supervisors
- Review applications promptly
- Provide constructive feedback on reports
- Be fair and consistent in evaluations
- Check notifications regularly

### General
- Keep your profile updated
- Use strong, unique passwords
- Report any issues to your administrator
