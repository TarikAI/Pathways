# 5. Auth.js v5 configuration

`lib/auth.ts` — NextAuth config exporting `{ handlers, auth, signIn, signOut }`. Credentials provider:
- Validate body with Zod (`email`, `password`).
- Look up user by email; compare with `bcrypt.compare`.
- Return `{ id, email, role, fullName, avatarUrl }`.
JWT callback adds `role` and `id` to the token; session callback exposes them on `session.user`.

`middleware.ts` runs `auth()`; redirects unauthenticated users from `(app)/*` to `/login`. Inside layouts, additionally call `requireRole(['STUDENT'])` etc. Server-side guards in API routes return 401/403.
