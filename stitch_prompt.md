# Google Stitch UI Generation Prompts

## Design System Configuration
*   **Name**: Pathways Theme
*   **Colors**:
    *   Primary: `#2F4156` (Navy)
    *   Secondary: `#567C8D` (Teal)
    *   Tertiary/Accent: `#C8D9E6` (Sky Blue)
    *   Background/Surface 1: `#F5EFEB` (Beige)
    *   Background/Surface 2: `#FFFFFF` (White)
*   **Typography**: Inter (Professional, clean, readable).

## Screen Generation Prompts

### 1. Landing / Login Page
> "Generate a professional landing and login page for 'Pathways', a university cooperative and field training management platform. The layout should have a clean, academic feel. Include the Pathways logo area at the top left. The right side should feature a login card with fields for Email and Password, and a dropdown or toggle to select user role: 'Student', 'Academic Supervisor', or 'Field Supervisor'. Use a white (`#FFFFFF`) card on a subtle beige (`#F5EFEB`) background, with a navy (`#2F4156`) primary button for 'Sign In'. Add a subtle illustration or graphic related to education and tech on the left side."

### 2. Student Dashboard
> "Create a dashboard for a Student user on the 'Pathways' platform. The layout should include a sidebar navigation with: 'Home', 'My Applications', 'Submit Report', 'Messages', and 'Settings'. The main content area should have a welcome banner. Below the banner, include a progress tracking widget showing the current stage of their internship. Add a section for 'Recent Notifications' and a prominent 'Submit Weekly Report' call-to-action button. Use the teal (`#567C8D`) and navy (`#2F4156`) colors for active states and headers, keeping the background light beige (`#F5EFEB`) and cards white (`#FFFFFF`)."

### 3. Supervisor Dashboard (Academic/Field)
> "Design a dashboard for an Academic or Field Supervisor. The sidebar should include 'Overview', 'My Students', 'Pending Reports', and 'Messages'. The main dashboard area needs a summary metrics row: 'Total Students Assigned', 'Reports Pending Review', and 'Unread Messages'. Below this, display a data table or a grid of cards listing the assigned students, their current status, and a button to 'View Profile' or 'Review Report'. Ensure the design looks highly professional and uses data visualization components if possible. Incorporate the navy (`#2F4156`) color for table headers and primary actions."

### 4. Report Submission Interface
> "Generate a report submission interface for students. It should feature a clean, step-by-step form or a structured page where a student can select the report type (e.g., Weekly, Final), attach a file (PDF/Word document upload area with drag-and-drop styling), and add optional comments in a text area. Include 'Cancel' and 'Submit Report' buttons. The form should be housed in a white card on a light background, prioritizing usability and clear instructions."

### 5. Messaging System Interface
> "Create a built-in messaging interface for communication between students and supervisors. The layout should feature a split-screen design: the left pane shows a list of recent conversations (chats) with names and brief preview text; the right pane shows the active chat window with a message history (chat bubbles) and a text input field at the bottom with a 'Send' button. Style the user's chat bubbles in sky blue (`#C8D9E6`) and the recipient's in white (`#FFFFFF`) or light gray, against a subtle background."
